# ResuCraft — Live Interactive Resume & CV Builder

A clean, responsive, real-time resume & CV builder built with HTML5, CSS3, and JavaScript.

## Features
- **Real-Time Split Preview**: Live updates as you type on the A4 preview sheet
- **Clean PDF / Print Export**: 1-click A4 formatted print export with dedicated print stylesheet
- **Dynamic Sections**: Add or remove work experience, education, projects, and skills
- **Multiple Color Themes**: Modern Navy, Executive Slate, and Emerald Growth
- **Auto-Save**: Saves changes to browser local storage automatically
